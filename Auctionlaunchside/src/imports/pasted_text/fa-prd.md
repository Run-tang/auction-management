## 1. 摘要

本文档定义「发拍申请端」的完整产品需求，支持卖家（车商/个人）在线提交车辆拍卖申请、管理申请状态、查看审核进度。核心目标是简化发拍流程、提高审核效率、降低填写流失率。

## 3. 背景

### 3.1 业务背景

平台当前处于成长期，车源供给是核心瓶颈。现有发拍流程依赖线下沟通，存在以下问题：

- 发拍流程繁琐，卖家流失率高
- 车辆信息不完整，审核反复沟通
- 无法实时查看申请进度，卖家体验差
- 竞品已支持在线发拍，需补齐能力

### 3.2 项目目标

| 目标类型 | 目标描述 | 衡量指标 |
|---------|---------|---------|
| 业务目标 | 提升发拍效率 | 平均发拍时长 ≤ 10分钟 |
| 业务目标 | 提高审核通过率 | 审核通过率 ≥ 85% |
| 业务目标 | 减少填写流失 | 草稿保存率 ≥ 60% |
| 用户目标 | 便捷提交申请 | 操作步骤明确，引导清晰 |
| 用户目标 | 实时查看进度 | 状态推送及时，进度可视 |

## 5. 详细需求说明

## 5.1 发拍申请列表页

### 5.1.1 页面概述

申请列表页是发拍申请的入口页面，展示用户所有发拍申请记录，支持按状态筛选和关键词搜索。

### 5.1.2 功能说明表

| 模块 | 功能说明 | 原型图 |
|------|---------|--------|
| 页面标题 | **功能说明**：显示"发拍申请"标题，右侧显示"+新建"按钮<br><br>**交互说明**：点击"+新建"跳转新建申请页 | - |
| 状态筛选 | **功能说明**：提供5个状态筛选标签：全部、草稿、待审核、已通过、已驳回。待审核标签显示未读数量红点<br><br>**交互说明**：点击标签即时筛选列表，选中状态高亮显示<br><br>**埋点说明**：点击事件 `fa_filter_click`，参数 `status` | - |
| 搜索框 | **功能说明**：支持按车辆品牌、车牌号、申请单号搜索<br><br>**交互说明**：输入关键词后实时过滤列表（无需点击搜索按钮）<br><br>**埋点说明**：搜索事件 `fa_search`，参数 `keyword` | - |
| 申请卡片 | **功能说明**：展示单条申请信息，包含车辆信息、状态标签、价格信息、时间、操作按钮<br><br>**交互说明**：点击卡片跳转申请详情页<br><br>**埋点说明**：点击事件 `fa_card_click`，参数 `application_id`、`status` | - |
| 悬浮按钮 | **功能说明**：固定在页面右下角的"+"按钮，快速新建申请<br><br>**交互说明**：点击跳转新建申请页<br><br>**埋点说明**：点击事件 `fa_float_create_click` | - |

### 5.1.3 申请卡片字段说明

| 字段名称 | 字段类型 | 显示规则 | 说明 |
|---------|---------|---------|------|
| 车辆名称 | 文本 | 品牌+车系+车型 | 主标题，如"宝马 5系 2022款 530Li" |
| 车牌号 | 文本 | 车牌号 | 副标题，如"沪A·12345" |
| 排量/变速箱 | 文本 | 排量+变速箱 | 副标题，如"2.0T自动" |
| 状态标签 | 标签 | 根据状态显示不同颜色 | 草稿(灰)、待审核(橙)、已通过(绿)、已驳回(红) |
| 期望价 | 数字 | 期望成交价+单位 | 高亮显示，如"38.50万"；未填写显示"待填写" |
| 起拍价 | 数字 | 起拍价+单位 | 如"35.00万"；未填写显示"待填写" |
| 里程 | 数字 | 表显里程+单位 | 如"3.2万km" |
| 时间/原因 | 文本 | 根据状态显示不同内容 | 待审核/已通过/草稿：显示申请时间；已驳回：显示驳回原因 |

### 5.1.4 空状态

| 场景 | 显示内容 |
|------|---------|
| 无申请记录 | 显示空状态图标、"暂无相关申请"、"+新建申请"按钮 |
| 搜索无结果 | 显示空状态图标、"未找到相关申请" |

## 5.2 新建发拍申请页

### 5.2.1 页面概述

新建申请页采用4步分步表单设计，引导用户逐步填写车辆信息。支持自动保存草稿、VIN码自动解析、价格校验等功能。

### 5.2.2 步骤指示器

| 元素 | 说明 |
|------|------|
| 步骤点 | 1-4数字，当前步骤橙色，已完成绿色，未完成灰色 |
| 连接线 | 步骤间的连接线，已完成绿色，未完成灰色 |
| 步骤标签 | 步骤名称：基本信息、车辆详情、价格设置、照片上传 |

### 5.2.3 步骤1：基本信息

#### 功能说明表

| 模块 | 功能说明 | 原型图 |
|------|---------|--------|

## 6. 状态机

### 6.1 申请状态流转

```
┌────────┐   提交审核   ┌────────┐   审核通过   ┌────────┐
│  草稿  │────────────→│待审核  │────────────→│已通过  │
└────────┘             └────────┘             └────────┘
     ↑                      │                      │
     │                      │ 审核驳回             │
     │                      ↓                      │
     │                 ┌────────┐                  │
     └─────────────────│已驳回  │                  │
         编辑后重新提交 └────────┘                  │
                           │                      │
                           │ 撤回                 │
                           ↓                      │
                      ┌────────┐                  │
                      │  草稿  │←─────────────────┘
                      └────────┘
```

### 6.2 状态说明

| 状态 | 英文 | 说明 | 允许操作 |
|------|------|------|---------|
| 草稿 | draft | 未提交或已撤回 | 编辑、删除、提交审核 |
| 待审核 | pending | 已提交等待平台审核 | 撤回、编辑 |
| 已通过 | approved | 审核通过，进入拍卖流程 | 查看 |
| 已驳回 | rejected | 审核未通过 | 查看原因、重新提交 |

### 7.3 关键漏斗

#### 发拍申请完成漏斗

```
fa_list_view (列表页浏览)
    ↓
fa_header_create_click / fa_float_create_click (点击新建)
    ↓
fa_form_view (进入表单)
    ↓
fa_next_step_click (步骤1→2)
    ↓
fa_next_step_click (步骤2→3)
    ↓
fa_next_step_click (步骤3→4)
    ↓
fa_submit_click (提交审核)
    ↓
fa_detail_view (查看详情)
```

#### 各步骤转化率

| 指标 | 计算公式 |
|------|---------|
| 列表→表单转化率 | fa_form_view / fa_list_view |
| 步骤1完成率 | fa_next_step_click(step=1, validation=pass) / fa_form_view |
| 步骤2完成率 | fa_next_step_click(step=2, validation=pass) / fa_next_step_click(step=1) |
| 步骤3完成率 | fa_next_step_click(step=3, validation=pass) / fa_next_step_click(step=2) |
| 步骤4完成率 | fa_submit_click / fa_next_step_click(step=3) |
| 草稿保存率 | fa_save_draft_click / fa_form_view |
| VIN扫描使用率 | fa_vin_scan / fa_form_view |

## 9. 验收标准

### 9.1 列表页验收标准

| 场景 | 验收条件 |
|------|---------|
| 页面加载 | 进入列表页，默认显示全部申请，按时间倒序排列 |
| 状态筛选 | 点击状态标签，列表即时刷新显示对应状态申请 |
| 搜索功能 | 输入关键词，列表实时过滤显示匹配结果 |
| 空状态 | 无申请时显示空状态引导 |
| 卡片点击 | 点击卡片跳转详情页 |
| 悬浮按钮 | 点击悬浮按钮跳转新建页 |

### 9.2 表单页验收标准

| 场景 | 验收条件 |
|------|---------|
| VIN解析 | 输入17位VIN后自动解析，成功后填充品牌车型信息 |
| 步骤切换 | 点击下一步验证通过后进入下一步，指示器同步更新 |
| 表单验证 | 必填项未填写时提示对应错误信息 |
| 价格验证 | 保留价<起拍价时显示错误提示 |
| 照片上传 | 上传照片后显示缩略图和勾选图标，计数更新 |
| 草稿保存 | 点击保存草稿后提示保存成功，列表页显示草稿记录 |
| 提交审核 | 提交成功后提示成功，列表页显示待审核记录 |

### 9.3 详情页验收标准

| 场景 | 验收条件 |
|------|---------|
| 信息展示 | 详情页显示申请的完整信息 |
| 状态按钮 | 根据申请状态显示对应的操作按钮 |
| 撤回申请 | 撤回成功后状态变为草稿 |
| 编辑申请 | 点击编辑跳转表单页，已填写内容回显 |
| 删除申请 | 删除成功后从列表移除 |
