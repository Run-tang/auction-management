## 一、产品概述

### 1.1 产品定位
优加发拍经销商端是面向二手车经销商的发拍申请管理工具，支持车辆信息录入、发拍申请提交、申请状态追踪、订单查看等功能。

### 1.2 目标用户
- 二手车经销商员工
- 内部员工账号（需后台创建，无账号提示"仅限内部员工使用，请前往申请"）

### 1.3 使用终端
- H5 移动端（适配手机浏览器）
- 微信小程序端（待接入）

## 三、登录模块

### 3.1 登录页

#### 页面元素
- Logo 与产品名称

## 四、发拍管理模块

### 4.1 发拍申请列表页

#### 页面标题
- 发拍管理

#### 顶部状态 Tab
| Tab名称 | 说明 |
|---------|------|
| 全部 | 展示全部申请 |
| 待审核 | 审核中的申请 |
| 已通过 | 审核通过的申请 |
| 已驳回 | 审核被驳回的申请 |
| 待发拍 | 待安排拍卖 |
| 待拍卖 | 已安排待拍卖 |
| 拍卖中 | 正在拍卖 |
| 交易成功 | 已成交 |
| 流拍 | 未成交 |
| 已下架 | 已下架的申请 |

#### 申请卡片字段

每个申请卡片展示以下信息：

| 字段 | 说明 |
|------|------|
| 车型名称 | 品牌+车系+车型 |
| 车牌号 | 7位数车牌 |
| 排量/变速箱 | 如：2.0T 自动 |
| 保留价 | 单位：万元 |
| 车辆状态 | 根据业务状态展示 |
| 里程 | 表显里程 + 单位（万公里） |
| 申请时间 | 提交申请的时间，驳回后更新申请时间 |

#### 卡片操作按钮（根据状态显示）

| 状态 | 操作按钮 |
|------|----------|
| 草稿 | 编辑发拍单、查看发拍单、删除（确认）、新增申请 |
| 待审核 | 查看发拍单、撤回（下架车辆）、新增申请 |
| 已通过 | 查看发拍单、查看订单、下架车辆 |
| 已驳回 | 查看发拍单、重新发拍 |
| 待发拍 | 查看发拍单、下架车辆 |
| 待拍卖 | 查看发拍单 |
| 拍卖中 | 查看发拍单 |
| 交易成功 | 查看发拍单、查看订单 |
| 流拍 | 查看发拍单、重新发拍 |
| 已下架 | 查看发拍单、重新发拍 |

#### 操作交互

1. **点击申请卡片** → 跳转至申请详情页
2. **编辑发拍单** → 跳转至编辑表单页
3. **查看发拍单** → 跳转至申请详情页（只读）
4. **下架车辆** → 二次确认弹窗"是否下架发拍申请"，确认后状态变更为"已下架"
5. **重新发拍** → 跳转至编辑表单页，修改后可重新提交
6. **撤回（下架）** → 二次确认后执行下架操作

#### 空状态
- 无申请记录时展示：
  - 空图标
  - 提示文字"暂无发拍申请"
  - 新增申请按钮

#### 悬浮按钮
- 位置：页面右下角
- 图标：+（新增）
- 作用：快速新增发拍申请

### 4.2 新增发拍申请页

#### 页面标题
- 新增发拍申请（新建时）
- 编辑发拍申请（编辑时）

#### 步骤进度条
- 顶部展示4个步骤进度
- 已完成步骤显示 ✅
- 当前步骤高亮
- 步骤：基本信息 → 车辆详情 → 价格设置 → 照片上传

#### Step 1：基础信息

##### 车辆识别
| 字段 | 必填 | 提示 | 校验规则 |
|------|------|------|----------|
| VIN码 | 必填 | 请输入17位VIN码 | 17位字母数字，自动转大写 |
| 车牌号 | 非必填 | 七位数 | 输入7位字符 |

##### 品牌车型
| 字段 | 必填 | 交互 |
|------|------|------|
| 品牌 | 必填 | 唤起品牌选择器 |
| 车系 | 必填 | 唤起车系选择器（根据品牌级联） |
| 车型名称 | 必填 | 选择对应的车型 |
| 年款信息 | 必填 | 选择车辆的年款 |

##### 车辆配置
| 字段 | 交互 |
|------|------|
| 排量 | 输入，最多10位字符 |
| 变速箱类型 | 单选：手动 / 自动 |
| 燃料类型 | 单选：汽油 / 柴油 / 电动 / 混动 |
| 车身颜色 | 单选：黑色 / 白色 / 银色 / 灰色 / 红色 / 蓝色 / 绿色 / 棕色 |
| 内饰颜色 | 单选：黑色 / 白色 / 银色 / 灰色 / 红色 / 蓝色 / 绿色 / 棕色 |

#### Step 2：车辆详情

##### 登记信息
| 字段 | 必填 | 交互 |
|------|------|------|
| 上牌日期 | 必填 | 日期选择器 |
| 表显里程 | 必填 | 数字输入，单位：万公里，最长5位，两位小数 |
| 过户次数 | - | 数字输入，单位：次，只允许输入1位数字 |
| 车辆性质 | - | 下拉选择：营运 / 非营运 |

#### Step 3：价格设置

##### 拍卖参数
| 字段 | 必填 | 说明 |
|------|------|------|
| 保留价 | 必填 | 单位：万元，最长7位，最多包含两位小数 |

##### 提示说明
- 保留价对买家不可见，低于保留价不成交

#### Step 4：照片上传

##### 必拍位置（必填）
| 位置 | 说明 |
|------|------|
| 前脸 | 必填 |
| 左前45° | 必填 |
| 右后45° | 必填 |
| 内饰 | 必填 |
| 仪表盘 | 必填 |
| 发动机舱 | 必填 |
| 后备箱 | 必填 |

> 说明：至少上传6张照片，均为必填

##### 补充照片（可选）
- 每类最多5张
- 瑕疵照片
- 改装照片
- 其他

#### 表单交互

1. **顶部进度条**
   - 展示4个步骤，已完成打 ✅
   - 点击上一步可返回修改
   - 点击下一步需当前页都填写完成才可进入下一步

2. **字段校验**
   - 必填字段未填写时，点击下一步弹出提示
   - VIN码格式校验（17位）
   - 价格格式校验（最多2位小数）

3. **提交流程**
   - 最后一步展示"提交审核"按钮
   - 点击提交显示 Toast："提交成功"
   - 拍卖后台收到提交后发送企微消息通知

4. **草稿保存**
   - 任意时刻可保存草稿
   - 保存后状态变为"草稿"

5. **返回确认**
   - 有未保存内容时，返回需二次确认

## 九、异常情况处理

### 9.1 登录异常
- 账号不存在：提示"账号不存在"
- 密码错误：提示"密码错误"
- 无权限账号：提示"仅限内部员工使用，请前往申请"

### 9.2 表单异常
- VIN码格式错误：提示"请输入17位VIN码"
- 必填字段未填写：提示具体字段名
- 价格格式错误：提示"最多输入两位小数"

### 9.3 网络异常
- 请求超时：提示"网络请求超时，请重试"
- 服务器错误：提示"服务异常，请稍后重试"
